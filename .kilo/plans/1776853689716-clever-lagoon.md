# UX/UI Improvements for Omsk System

## Focus Areas (User-Confirmed)
1. Mobile responsiveness + better loading states (quick wins)
2. Quick reorder button (user convenience)
3. Scope: Omsk only
4. Preference: Polish existing, new features OK

---

## Implementation Plan

### Feature 1: Better Loading States

**Quick wins - Low Effort**

**Current State:**
- OmskApp.tsx uses generic "Загрузка..." text
- No skeleton loaders
- No visual distinction between loading states

**Changes:**
- Add skeleton loader component for order list
- Add skeleton for order form
- Add loading spinner/progress for order submission
- Refactor `isLoadingOrders` state to show skeletons

**Files to modify:**
- `src/components/OmskApp.tsx` - Add skeleton components
- Create new: `src/components/ui/Skeleton.tsx`

---

### Feature 2: Mobile Responsiveness

**Medium Effort**

**Current Issues in OmskApp.tsx:**
- Date picker (line 401-407) takes full width on mobile
- Address selection buttons may overflow
- Order list cards not optimized
- Department filter (line 383-399) needs collapse on mobile

**Changes:**
- Wrap date input with responsive constraints
- Make filters collapsible on small screens
- Add touch-friendly tap targets (min 44px)
- Stack address buttons vertically on mobile

**Files to modify:**
- `src/components/OmskApp.tsx` - Responsive adjustments

---

### Feature 3: Quick Reorder Button

**Low Effort - High Value - CONFIRMED: Pre-fill (user reviews then confirms)**

**Current State:**
- Users must re-select all items each time
- Name/department auto-saved but not dishes

**Changes:**
- Save last completed order to localStorage on submit
- Add "Повторить заказ" button in order form
- Button pre-fills form with saved items
- User reviews then clicks confirm (safest UX)

**UI Placement:**
- Button: "Повторить заказ" next to form submit
- Shows saved items count: "3 блюда"
- Tapping fills form (does NOT auto-submit)
- User reviews → clicks "Заказать" to confirm

**Edge case:** Clear saved order if date changes (for next-day ordering)

**Files to modify:**
- `src/components/OmskApp.tsx` - Add repeat button + localStorage
- May need new utility in `src/utils/localStorage.ts`

## Technical Details

### Skeleton Component Spec
```tsx
// Simple skeleton for React
<div className="animate-pulse">
  <div className="h-4 bg-gray-200 rounded w-3/4"></div>
  <div className="h-4 bg-gray-200 rounded w-1/2"></div>
</div>
```

### Quick Reorder Data Structure
```ts
// localStorage key: omsk_lastOrder
interface LastOrder {
  employeeName: string;
  department: string;
  items: OrderItem[];
  address: string;
  orderDate: string; // optional
}
```

### Mobile Breakpoints
- Tailwind uses `sm: 640px`, `md: 768px`
- Target: stack vertically below 640px
