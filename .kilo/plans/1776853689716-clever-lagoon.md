# UX/UI Improvements for Omsk System

## Overview
Plan for enhancing user experience and interface in the Omsk lunch ordering system.

### Examined Files
- `src/components/OmskApp.tsx` - Main ordering interface (554 lines)
- `src/components/OmskAdmin.tsx` - Admin panel (1400+ lines)

---

## Proposed Improvements

### 1. Order Form Enhancements

**Current Issues:**
- Single-page form may be overwhelming
- Limited visual feedback during selection
- No "last ordered" quick reorder

**Proposed:**
- Add dish category thumbnails with images
- Quick-reorder from history button
- Animated cart summary sidebar
- Better quantity controls

### 2. Mobile Experience

**Current Issues:**
- Date picker and filters take excessive space on mobile
- Order list scrolling may be janky

**Proposed:**
- Responsive card-based order list
- Collapsible filters on mobile
- Bottom navigation for key actions
- Pull-to-refresh for orders

### 3. Visual Feedback & States

**Current:** Basic loading text and error displays

**Proposed:**
- Skeleton loaders for orders
- Micro-animations on order submit (confetti on success)
- Toast notifications with icons
- Order delete confirmation animation

### 4. Address Selection

**Current:** Dropdown with address list

**Proposed:**
- Interactive map pins for coffee shops (if coordinates available)
- Address cards with photos
- Distance estimatedelivery time

### 5. Admin Dashboard Improvements

**Current:** Tab-based interface

**Proposed:**
- Dashboard overview with daily stats
- Quick action buttons (export, disable dates)
- Order volume charts by day/department
- Kitchen print-friendly view

### 6. Accessibility

**Proposed:**
- Keyboard navigation improvements
- High contrast mode support
- Screen reader labels
- Focus indicators

### 7. Data Visualization

**Proposed:**
- Department order breakdown pie chart
- Popular dishes ranking
- Weekly order trends
